What is this?

Random Fun Generator shows a random dog photo paired with a random piece of advice. Click Generate for a new pair, or Save to Favorites to keep the ones you like. Favorites are stored in your browser and survive page reloads.

Data sources

  • Dog CEO API — random dog images
  • Advice Slip API — random advice

No accounts, no tracking, no server — everything runs in your browser.
